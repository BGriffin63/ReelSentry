# ReelSentry — Support

## Getting help
1. Check [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md).
2. Open **Settings → ReelSentry → Diagnostics** and download the **sanitized**
   support bundle (secrets are redacted — safe to share).
3. Search existing GitHub issues.
4. Open a new issue using the appropriate template, or post in the community
   support thread: `https://github.com/BGriffin63/ReelSentry/issues`.

## What to include
- Unraid version and ReelSentry version (Diagnostics tab).
- What you expected vs. what happened.
- Relevant Event History rows (VMs, event types, timestamps).
- The sanitized diagnostics bundle.

## Support policy
This is a community project maintained by an individual. Best-effort support; no
SLA. Security issues are prioritized — see [`../.github/SECURITY.md`](../.github/SECURITY.md).

## Scope
- **In scope:** ReelSentry behavior, notifications, health checks, install/upgrade/
  uninstall, diagnostics.
- **Out of scope:** general Unraid configuration, Discord server administration,
  guest-OS issues, and third-party notification agents (configure those in
  Unraid's own Notifications settings).
